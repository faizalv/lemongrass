# Roadmap

Planned features, not yet in a release. They arrive through the app's own update, free.

- **Lemongrass workspace.** A virtual file system that lets agents work in isolation while staying aware of everything around them.
- **Sibling projects.** Agents switch between project folders seamlessly, without losing their prompt cache.
- **Lightweight language server plugins.** Agents drive live, deterministic debugging together with you.
- **Point a whole app at a database channel.** A local port that speaks the MySQL or Postgres wire protocol, so an app's own driver goes through the same vault and scope as `lgrass db`.
- **A second opinion on command asks.** An advisory reviewer, a small model run outside Lemongrass, comments on a command an agent asks you to run before you decide.
- **A browsable channel audit.** Every database and API call through a channel, database reads included, in one place you can search.
- **An investigator role for workgroups.** Cheap, read-only members that dig through code and report to the leader.

Have a weird idea? Open an issue on [GitHub](https://github.com/faizalv/lemongrass/issues).
