---
name: lgrass-howtodo-newlaws
description: Use before writing anything into biblio/laws/, and when a correction might become a standing rule.
---

When a correction or a repeated mistake might be a standing rule, offer it in chat: the rule in one sentence, then Why and How to apply. Write nothing to `biblio/laws/` or memory until the user says yes to that law.

Only an explicit yes counts. A question, a reword request or silence does not: revise and ask again. After a no, never offer it again.

On yes, write `biblio/laws/<slug>.md` (title, rule, Why, How to apply, no dates) and one line in `biblio/laws/summary.md`, in the same turn. Never in memory.
