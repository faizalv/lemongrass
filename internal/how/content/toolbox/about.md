The toolbox, `biblio/toolbox/`, holds working files that other work will use again, such as scripts, queries and runbooks: material that is not a law, not a book and not one task's record. Each item is a folder `biblio/toolbox/<slug>/` with one line in `biblio/toolbox/inventory.md`. Only `lgrass toolbox` changes it, since the hooks refuse any direct write there, and it holds at most 40 items.
